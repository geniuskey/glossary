# 제품 도움말

Glossary 앱의 `/help`에서는 용어 검색, 시트 편집, 새 용어 등록, 함께 정리, 관계도,
용어 챗봇과 엑셀 가져오기로 바로 이동할 수 있다.

## 용어 챗봇

사이드바의 **용어 챗봇**에서 사내 용어·약어·권장 표기를 질문할 수 있다. 챗봇은
질문과 연결된 공개 용어를 먼저 찾고 그 내용만 AI에 전달하며, 답변 아래에 참고한 용어
링크를 표시한다. 연결되는 용어가 없으면 일반 지식으로 추측하지 않는다. 관리자가
관리자 패널의 **AI 연결**에서 Gemini 또는 OpenAI-compatible API를 먼저 설정해야 한다.
모르는 용어가 나오면 Full name·정의·설명을 대화로 알려주고 확인 카드에서 비공개 초안으로
추가할 수 있다. 기존 용어집의 표·목록을 여러 줄로 붙여넣으면 최대 25개 초안으로 정리한다.
API 키를 입력하거나 저장된 키가 있으면 선택 가능한 모델 목록을 자동으로 불러온다.
목록 API를 제공하지 않는 호환 서버는 모델 이름을 직접 입력할 수 있다.
`Connected`는 목록 조회가 아니라 선택한 모델의 실제 생성 요청까지 성공했을 때 표시된다.

관리자 패널의 **콘텐츠 완성도**는 모든 용어에 같은 분량을 강제하지 않는다. 플랫폼이
Full name이 있는 약어·식별자·단위는 표기 매핑, 일반 용어는 맥락 설명, 폐기·금지 용어는
사용 지침으로 자동 판단한다. 보완이 필요한 용어는 `함께 정리`에서 확인할 수 있다.
