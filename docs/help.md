# 제품 도움말

Glossary 앱의 `/help`에서는 용어 검색, 시트 편집, 새 용어 등록, 함께 정리, 관계도,
용어 챗봇과 엑셀 가져오기로 바로 이동할 수 있다.

## 처음 사용하는 순서

이미 설치된 Glossary 주소에 접속해 로그인한다. 계정 생성이나 회사 계정 로그인 방식은
운영자가 설정한다. 직접 서버를 설치하려면 [설치와 운영](/operations)을,
소스를 수정하려면 [개발 환경 시작하기](/guide/getting-started)를 따른다.

1. **검색**: 홈에서 알고 있는 이름이나 약어를 입력한다. 상세 화면에서 정의·도메인을
   확인해 같은 표기의 다른 개념과 구분하고, 대표 표기와 사용 지침을 확인한다.
2. **등록**: 검색으로 기존 용어를 먼저 확인한 뒤 **새 용어**에서 이름과 정의를 작성한다.
   같은 뜻의 약어·별칭은 별도 개념을 만들기보다 기존 용어의 표기로 정리한다.
3. **편집**: 상세 화면에서 내용을 보완한다. 다른 사람이 먼저 저장해 충돌이 나면
   최신 내용을 다시 확인하고 수정한다. 이전 내용은 수정 이력에서 확인하고 되돌릴 수 있다.
4. **함께 정리**: 보완할 용어를 찾고 담당자·분류·관계를 정리한다.
   `기준 충족`은 작성 요건을 채웠다는 뜻이며 공식 승인이나 정확성 보증을 뜻하지 않는다.

## 기존 용어집 가져오기와 공유

- **엑셀 가져오기**: `/import`에서 파일을 올리고 dry-run 결과의 오류·중복을 확인한 뒤
  반영한다. 입력 형식과 제한은 [임포트 문서](/api/import)를 참고한다.
- **시트 공유**: `/sheet`의 **공유하기**에서 필터와 표시 열을 고른 뒤 URL을 복사한다.
  Confluence에 넣으려면 운영자의 iframe 출처 설정과 사용자의 Glossary 로그인이 필요하다.
  자세한 절차는 [협업과 관계도](/guide/collaboration)를 참고한다.

## 용어 챗봇

사이드바의 **용어 챗봇**에서 사내 용어·약어·권장 표기를 질문할 수 있다. 챗봇은
질문과 연결된 용어를 먼저 찾고 그 내용만 AI에 전달하며, 답변 아래에 참고한 용어
링크를 표시한다. 연결되는 용어가 없으면 일반 지식으로 추측하지 않는다. 관리자가
관리자 패널의 **AI 연결**에서 Gemini 또는 OpenAI-compatible API를 먼저 설정해야 한다.
모르는 용어가 나오면 Full name·정의·설명을 대화로 알려주고 확인 카드에서 용어로
추가할 수 있다. 상태는 내용에 따라 자동 판정되며 비공개를 뜻하지 않는다. 기존 용어집의 표·목록을 여러 줄로 붙여넣으면 최대 25개 등록안으로 정리한다.
API 키를 입력하거나 저장된 키가 있으면 선택 가능한 모델 목록을 자동으로 불러온다.
목록 API를 제공하지 않는 호환 서버는 모델 이름을 직접 입력할 수 있다.
`Connected`는 목록 조회가 아니라 선택한 모델의 실제 생성 요청까지 성공했을 때 표시된다.

관리자 패널의 **콘텐츠 완성도**는 모든 용어에 같은 분량을 강제하지 않는다. 플랫폼이
Full name이 있는 약어·식별자·단위는 표기 매핑, 일반 용어는 맥락 설명, 폐기·금지 용어는
사용 지침으로 자동 판단한다. 보완이 필요한 용어는 `함께 정리`에서 확인할 수 있다.
