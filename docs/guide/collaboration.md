# 담당자·분류·관계도

## 용어별 담당자

새 용어와 편집 화면에서 현재 사용자 한 명을 담당자로 지정할 수 있다. 담당자는 승인 권한을
독점하는 사람이 아니라, 해당 용어를 읽을 수 있는 수준까지 정리할 책임자다. 다른 편집자도
계속 내용을 보탤 수 있으며, 담당자가 탈퇴하면 값은 자동으로 미지정 상태가 된다.

`함께 정리` 화면에서는 내 담당 용어가 먼저 나오고, 각 카드와 상세 화면에서 담당자를 확인한다.

SSO 사용자는 로그인할 때 IdP가 확인해 준 group/조직이 이름 뒤에 표시된다. 여러
그룹이 전달되면 모두 표시하며, 로컬 계정이나 그룹 claim이 없는 계정은 이메일을 표시한다.
예를 들어 `Platform 조직` claim이 확인된 사용자는 담당자 선택과 목록에서
`김민지 · Platform 조직`으로 표시된다.

## Type·업무 분류·주제·도메인

- **Type**: 대상 자체의 성격. 일반 개념·고유명칭·식별자·단위 중 하나다.
- **업무 분류(Category)**: 제품·고객·프로젝트·공정·설계처럼 조직이 관리하는 공통 목록 중 하나다.
- **주제(Topic)**: 팀별로 필요한 세부 분류를 자유롭게 적는다.
- **도메인**: 용어가 쓰이는 넓은 기술·업무 영역이며 여러 개를 지정할 수 있다.

도메인은 `/classifications`에서 72개의 옅은 팔레트 중 하나를 선택한다. 이미 다른 도메인이
사용하는 색은 선택할 수 없으며 DB 고유 제약도 중복 저장을 막는다. 새 도메인은 아직 쓰지
않은 색을 자동으로 받는다.

`약어`는 Type이 아니라 추가 표기의 종류다. 예를 들어 `Auto Exposure`와 `AE`는 하나의
일반 개념에 풀네임·약어 표기로 함께 등록한다. 시트에서는 네 축을 각각 열과 필터로 쓴다.

관리자는 `/classifications`의 **업무 분류**에서 항목을 추가하고 표시 이름과 순서를 바꿀 수 있다.
표시 이름을 바꿔도 내부 key는 유지되므로 기존 용어와 공유 URL은 깨지지 않는다. 사용 중인
분류는 용어가 남아 있는 동안 삭제할 수 없다.

## 관계도

`/graph`는 별도의 관계를 추측해 저장하지 않는다. 실제로 관리하는 도메인·업무 분류·주제를
허브로, 용어를 노드로 그려 같은 맥락의 용어를 탐색한다. 각 필터로 큰 그래프를 좁힐 수 있다.
도메인 허브는 분류 체계에 저장한 옅은 색을 사용한다. 용어 노드는 업무 분류 색을 우선하고,
업무 분류가 없을 때 대표 도메인의 저장 색을 사용한다.

## 시트 열 레이아웃

`/sheet`의 열 너비는 셀 내용이나 정렬 결과와 무관하게 고정된다. 머리글을
끌어 열 순서를 바꾸고, 머리글 오른쪽 경계를 끌어 너비를 조절한다. 키보드에서는 머리글이나
열 경계에 포커스를 둔 뒤 왼쪽·오른쪽 방향키를 사용할 수 있다.

상단의 **열 설정**에서는 열 표시 여부와 순서를 함께 조정한다. 표시 여부·순서·사용자가 바꾼
너비는 현재 브라우저의 로컬 저장소에 자동으로 남아 새로 고침하거나 다시 방문해도 유지된다.
다른 브라우저나 기기로는 공유되지 않는다. 기본 구성으로 돌아가려면 **열 설정 → 열 레이아웃
초기화**를 누른다.

## Confluence 임베드

`시트` 상단의 **공유하기**를 누르면 읽기 전용 표를 만들 수 있다. 현재 검색·필터는
시작값일 뿐이며, 공유 창에서 검색어·Type·공개 상태·도메인·업무 분류·주제를 각각 바꾸거나
`전체`로 해제할 수 있다. `표시할 열`에서 필요한 열만 체크하고, 촘촘한 행·상세 링크·바깥
테두리 여부를 고른다. 같은 설정으로 다음 두 결과를 각각 복사할 수 있다.

- **공유 URL**: 새 탭에서 열거나 Confluence URL 매크로에 붙인다.
- **iframe 코드**: HTML/iframe 삽입을 지원하는 매크로에 붙인다.

<img src="/images/sheet-share.png" width="1440" height="960" loading="lazy" alt="시트 공유 창에서 표시할 열과 공유 옵션을 선택하는 화면">

열 정의는 `columns` 쿼리에 표준 열 키의 쉼표 목록으로 들어간다. 주소를 직접 만들 수도
있지만, 알 수 없는 열 키는 무시되고 유효한 열이 하나도 없으면 기본 열 구성을 사용한다.

```text
https://glossary.example.com/embed?domain=ISP&category=design&topic=노출%20제어&sort=nameEn&dir=asc&columns=nameEn,nameKo,domain,category,definitionMd&compact=1&links=1&border=1
```

```html
<iframe src="https://glossary.example.com/embed?..." title="Glossary 용어 시트" width="100%" height="560" loading="lazy" style="border:1px solid #e7e3dc;border-radius:8px"></iframe>
```

<img src="/images/sheet-embed.png" width="1440" height="960" loading="lazy" alt="선택한 열만 표시하는 읽기 전용 용어 시트 임베드 화면">

운영 환경에는 iframe을 허용할 Confluence origin을 설정한다.

```dotenv
GLOSSARY_EMBED_ANCESTORS=https://confluence.example.com
```

여러 출처는 쉼표로 구분한다. 값이 비어 있으면 동일 출처 외에는 프레임 삽입이 차단된다.
공유 표는 최대 200개의 공개 상태 용어만 보여 주며 초안은 노출하지 않는다. 임베드 화면도
Glossary 로그인을 요구한다. 브라우저의 서드파티 쿠키 제한을 피하려면
Glossary와 Confluence를 같은 사이트 범위의 서브도메인으로 운영하는 편이 안전하다.
