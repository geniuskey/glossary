# 제품 리뷰와 개선 — 2026-09-09

## 판단

Glossary의 핵심 가치는 조직에서 같은 개념을 여러 이름으로 부르더라도 뜻과 사용 지침을
찾을 수 있게 만드는 데 있다. 개념·표기 분리, 표기 정규화, 수정 이력, 조회 API는 이 목적에
맞는 기반이다. 다만 기능을 갖춘 것과 사용자가 실제로 가치를 얻는 것은 별개다.
홈에서 시작할 작업을 쉽게 선택하게 하고, 작성 상태와 내용의 신뢰도를 구분할 필요가 있다.

이번 리뷰는 README, 홈, 공통 탐색·검색, 소개 화면, 가져오기 진입 화면,
검색·분류 집계·작성 요건 코드와 관련 테스트를 확인한 코드 기반 평가다.
전체 기능 감사나 실사용자 조사, 운영 데이터 분석을 수행한 것은 아니다.

## 다음에 검증할 가치

아래는 아직 측정하지 않은 가설과 후속 검증 항목이다. 자동 수집 기능을 추가하지 않았다.

1. 새 팀원이 실제 문서에서 가져온 약어의 뜻을 도움 없이 찾는지 관찰한다.
   찾는 데 걸린 시간과 결과가 없었던 이유를 기록한다.
2. 문서 작성자가 비권장·금지 표기를 검색한 뒤 적절한 대체 표기를 선택하는지 확인한다.
   개념의 대표 이름만으로 사용 문맥별 대안을 충분히 안내하는지도 확인한다.
3. 담당자가 정리 대기 목록에서 다음에 보완할 용어를 선택할 수 있는지 확인한다.
   등록 수 증가와 별개로 정의·사용 예시가 동료의 질문을 해결하는지 평가한다.
4. 공식 표준 확정이 필요한 조직인지 확인한다. 현재 위키형 편집·이력 관리에 별도의 승인
   모델을 섞기 전에, 작성 요건·공개 상태·조직 합의를 구분하는 운영 정책부터 정한다.

## 검증

- 웹 TypeScript 검사 통과.
- 웹 프로덕션 빌드 통과 (Next.js 16.3.2).
- 기존 관련 테스트 5개 파일, 40개 통과: 검색 유틸리티, 홈 탐색, 앱 셸,
  화면 규약, 검색어를 유지한 신규 등록 경로.
- 해당 테스트는 DB에 접근하지 않으며 실행 시 연결 불가능한 테스트 전용 URL을 지정했다.
  DB 통합 테스트를 실행한 것으로 해석하면 안 된다.
- `git diff --check` 통과.
- 실제 브라우저의 화면 크기별 배치, 스크린리더, 자동완성 요청 경합은 직접 검증하지 않았다.
  기존 테스트 통과는 이 동작의 브라우저 검증을 대체하지 않는다.

접근성·탐색 검토 기준: [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md).

## 후속 개선 — 가져오기와 시트 검색

첫 개선 커밋 `d9e1231`을 `main`에 푸시한 뒤 다음 흐름을 추가 점검했다.

- `apps/web/src/components/import-form.tsx`: 가져오기 완료 후 파일 선택이 잠긴 채 후속
  작업이 없던 문제를 수정했다. 시트 확인과 다른 파일 가져오기를 제공하고, 다시 시작할 때
  이전 파일·검사 결과·강제 등록 선택을 초기화한다.
- `apps/web/src/components/import-form.tsx`: 전체 행은 있지만 등록 가능한 행은 0개인
  경우에도 등록 버튼이 활성화되던 문제를 수정했다. 실제 대상 행 수와 파일 오류로 버튼과
  요청을 함께 제한한다. 요청 중 강제 등록 선택도 잠가 제출 내용과 화면이 달라지지 않게 한다.
- 파일 선택 영역에 키보드 포커스 표시를 추가하고 ‘dry-run’을 ‘등록 전 검사하기’로 바꿨다.
- `apps/web/src/lib/import/form-response.ts`: 검사 응답에 화면이 사용하는 배열이 없거나
  행 수가 잘못된 경우, 화면 오류 대신 재시도 가능한 오류 문구를 표시하도록 검증을 보강했다.
  누락된 필드와 잘못된 행 수에 대한 회귀 테스트 5개를 추가했다.
- `apps/web/src/components/sheet-filter-bar.tsx`: 클릭할 검색 버튼, 요청 진행 상태,
  모바일 검색 키 힌트를 추가했다. 검색어 지우기 후 입력창으로 포커스를 돌린다.
- `apps/web/src/components/terms-grid.tsx`: 필터로 비어 있는 목록에서는 먼저 검색·필터
  해제를 안내한다. 전체 목록으로 돌아가는 링크를 제공해 신규 등록 전에 기존 용어를 확인하게 한다.

검증: 타입 검사, 프로덕션 빌드와 관련 8개 테스트 파일의 142개 테스트가 통과했다.
브라우저 연결을 시도했지만 사용 가능한 브라우저가 없고 로컬 Docker 엔진도 실행되지 않아,
실제 화면·DB 통합 검증은 수행하지 않았다.
