# 지원

Grossary는 셀프호스팅 소프트웨어다. 특정 인스턴스의 계정, 권한, 데이터, 네트워크와
백업 문제는 해당 배포 운영자에게 문의한다.

## 프로젝트 지원 채널

- [기존 이슈 검색](https://github.com/geniuskey/grossary/issues)
- [버그 신고](https://github.com/geniuskey/grossary/issues/new?template=bug_report.yml)
- [기능 제안](https://github.com/geniuskey/grossary/issues/new?template=feature_request.yml)
- [문서 문제](https://github.com/geniuskey/grossary/issues/new?template=documentation.yml)
- [보안 취약점 비공개 신고](https://github.com/geniuskey/grossary/security/advisories/new)

버그에는 재현 단계, 기대 결과, 실제 결과, 배포 방식과 민감 정보를 제거한 로그를 적는다.
비밀번호, API 키, 세션 쿠키, SSO secret과 사내 데이터는 공개 이슈에 올리지 않는다.

자세한 정책은 저장소의 [SUPPORT.md](https://github.com/geniuskey/grossary/blob/main/SUPPORT.md)와
[SECURITY.md](https://github.com/geniuskey/grossary/blob/main/SECURITY.md)를 따른다.
