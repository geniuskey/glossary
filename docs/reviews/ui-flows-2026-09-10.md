# UI 작업 흐름 추가 개선

2026-09-10, [첫 UI 리뷰](./ui-ux-2026-09-10.md)에 이어 작성 내용 보존과 비동기 작업을 점검했다.

## 재현한 문제와 수정

- 새 용어를 입력한 뒤 검색 자동완성을 Enter로 선택하면 저장하지 않은 변경사항 경고를 우회했다. 실제 브라우저에서 입력 내용을 잃고 `/w/sla`로 이동하며 확인 대화상자는 0회 발생하는 것을 확인했다. 검색 후보를 `Link`로 바꾸고 키보드도 같은 링크를 실행하도록 수정했다. 취소 시 입력을 유지하고, Ctrl+클릭은 기존 화면을 유지한 채 새 탭을 연다.
- 챗봇의 대화 삭제는 확인 없이 바로 DELETE를 실행했다. 테스트 응답으로 재현한 뒤 삭제 확인, 진행 상태, 네트워크/서버 실패 안내를 추가했다. 삭제 실패는 현재 대화를 숨기지 않고 재시도를 허용한다.
- 대화 이동과 브라우저 뒤로가기의 조회 경로가 달랐다. `usePathname`에서 대화 ID를 읽어 기록을 복원하고, 이전 GET 요청을 취소하며 늦은 응답을 무시하도록 통일했다.
- 답변이나 용어 생성 결과가 다른 대화에 섞이지 않도록 요청 당시 대화를 확인한다. 용어 생성은 시작 시점의 메시지를 바탕으로 해당 대화에 기록한다.
- 대화 조회 실패에 다시 불러오기를 추가하고, 기록을 불러오는 동안 질문 전송을 막았다. 새 대화/다른 대화로 이동할 때 작성 중인 질문이 있으면 확인한다.
- 용어 편집, 프로필, 홈 소개 편집이 공통 이탈 경고를 사용한다. 새 탭·다운로드·같은 문서의 앵커 이동은 제외한다. 홈 소개에는 미저장 상태와 기본 문구 교체 확인을 추가하고 저장 완료 후 변경 상태를 해제한다.

리뷰에는 [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)의 링크 의미, 작성 중 이탈, 파괴적 작업 확인, 오류 복구 기준을 활용했다.

## 검증 결과

- `pnpm --filter @glossary/web build`: 최적화 빌드, TypeScript, 정적 페이지 생성 완료.
- `pnpm --filter @glossary/web typecheck`: 통과.
- 관련 Vitest 12개 파일, 93개 테스트 통과. 기존 UI 구조 검사와 검색/Markdown/색 대비 검사를 포함한다.
- 변경된 6개 화면(`/new`, `/settings`, `/admin`, `/chat`, `/sheet`, `/?q=s`)을 320·390·768·1440px에서 확인한 24개 조합: 문서 가로 넘침과 콘솔 오류 없음.
- 실제 브라우저 회귀 검사 13개 통과, 건너뛴 검사 없음. 외부 AI와 실제 설정 저장/대화 삭제를 호출하지 않고 테스트 응답을 사용했다.

### 브라우저 회귀 검사

[`scripts/ui-flows.browser.js`](../../scripts/ui-flows.browser.js)는 별도 검사 탭을 만들고 다음 동작을 검증한 뒤 닫는다.

1. 자동완성 클릭·Enter의 이탈 경고와 입력 보존
2. Ctrl+클릭 새 탭 열기
3. 이탈 승인 후 이동
4. 프로필 이탈 경고·저장 실패 보존·저장 후 이동
5. 홈 문구 기본값 교체·이탈 취소·저장 상태 갱신
6. 대화 삭제 취소 시 요청 없음
7. 삭제 실패 안내와 재시도 가능 상태
8. 대화 전환·뒤로가기·앞으로가기의 URL/선택 일치
9. 응답 대기 중 뒤로가도 다른 대화의 답변이 섞이지 않음
10. 늦게 도착한 이전 대화 응답 무시
11. 대화 조회 실패 후 재시도
12. 대화 삭제 성공 후 새 대화 상태
13. 첫 답변 실패 후 URL·질문·오류 안내 보존

재실행하려면 로컬 앱 `http://localhost:3000`에 로그인한 Playwright MCP 컨텍스트에서 `browser_run_code_unsafe`의 `filename`에 이 파일의 절대 경로를 넘긴다. 전체 검사는 관리자 계정과 AI 기능이 활성화된 화면을 요구한다. 권한/활성화 조건이 없으면 해당 검사를 `skipped`에 명시한다. API 쓰기는 차단하거나 가짜 응답을 반환하므로 실제 용어나 대화를 만들거나 삭제하지 않는다. Ctrl+클릭 검사는 Windows Chromium 기준이다.

이번에 만든 로컬 검증 계정과 세션은 검증 후 삭제했다. 프로필과 홈 소개의 저장 성공 검사는 가짜 API 응답이며, 서버 저장 로직 전체나 실제 AI 응답 품질을 검증한 것은 아니다. 공통 이탈 경고는 링크 이동과 문서 닫기를 보호하며 브라우저 강제 종료 복구나 자동 초안 저장 기능은 추가하지 않았다.
